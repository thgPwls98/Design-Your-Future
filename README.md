# DYF (Design Your Future)

> 웹 크롤링 기반 대외활동·공모전 정보 통합 Android 애플리케이션

- **개발 기간:** 2024.09 ~ 2024.12
- **팀 구성:** 4인 팀 프로젝트
- **주요 기술:** Python, Selenium, BeautifulSoup, Flask, Firebase Firestore, Android Studio (Java)

## 프로젝트 소개

여러 사이트에 흩어져 있는 대외활동과 공모전 공고를 수집하고 모바일 앱에서 확인할 수 있도록 만든 프로젝트입니다. 크롤링한 정보를 데이터베이스에 저장하고 Android 앱에서 조회할 수 있는 데이터 흐름을 구성했습니다.

## 주요 기능

- 웹사이트에서 대외활동·공모전 정보 수집
- 모집 상태를 고려한 공고 데이터 관리 및 갱신
- 키워드 기반 공고 검색 및 결과 조회
- Firestore에 저장된 공고를 Android 앱에서 표시

## 시스템 흐름

```text
외부 공고 웹사이트
      ↓
Python 크롤링 (Selenium / BeautifulSoup)
      ↓
Flask 기반 데이터 처리 및 API
      ↓
Firebase Firestore
      ↓
Android 앱 (Java)
```

키워드 검색 등 일부 기능에서는 앱의 요청에 따라 서버 측 크롤링과 데이터 갱신을 수행하도록 구성했습니다.

## 담당 역할

- Python·Selenium 기반 공고 크롤링 기능 개발
- Flask를 활용한 API 및 서버 측 데이터 처리 기능 구현
- Firestore 데이터 구조 설계와 공고 저장·갱신 흐름 구성
- Android 앱과 서버·데이터베이스 연동 작업 참여

> 팀 프로젝트로 진행했으며, Android UI/UX 레이아웃과 주요 화면 개발은 다른 팀원이 담당했습니다.

## 기술 선택 배경

- **Selenium / BeautifulSoup:** 웹페이지에서 공고 정보 수집 및 파싱
- **Flask:** 크롤링·데이터 처리 기능을 앱에서 호출할 수 있도록 연결
- **Firestore:** 수집된 공고 저장 및 Android 앱 연동

## 프로젝트를 통해 배운 점

단순한 크롤링을 넘어 데이터 수집, 서버 처리, DB 저장, 모바일 앱 조회까지 이어지는 흐름을 경험했습니다. 데이터가 최신 상태로 유지되도록 관리하는 과정의 중요성도 배웠습니다.

## 실행 및 참고 사항

이 저장소는 학부 팀 프로젝트의 코드 기록입니다. 현재 환경에서의 재실행 여부와 외부 사이트 크롤링 가능 여부는 별도 확인이 필요합니다. 실행에 필요한 환경변수와 Firebase 설정은 각자의 개발 환경에서 구성해야 합니다.
